# Vantara Product Foundation

## Definition

**Vantara converts the operation of a hotel into a connected system.**

The platform connects the people, rooms, reservations, guests, requests, services and operational signals that make a hotel run.

## Primary product pillars

### 1. Hotel Core
The operational source of truth:
- reservations
- rooms
- guests
- properties
- payments

### 2. Vantara Connect
The communication layer between guest and hotel:
- requests
- conversations
- services
- notifications
- guest experience

### 3. Vantara Intelligence
The decision and automation layer:
- operational insights
- CRM intelligence
- alerts
- automation
- future predictive capabilities

### 4. Vantara Data
The connected operational data layer that makes the other pillars coherent.

### 5. Vantara Cloud
Infrastructure, integrations, reliability and security.

## First user journey

```
REGISTER

  -> PROPERTY

  -> ROOMS
  -> DASHBOARD
```

## Foundation milestone

`FOUNDATION-001`

Deliver a secure hotel workspace with the minimum operational entities required to represent a real property.

## Definition of done

A foundation feature is not done until:
- tenant isolation is enforced
- authorization is explicit
- inputs are validated
- persistence is real
- meaningful errors are handled
- tests cover critical behavior
- UI reflects actual backend state
- documentation matches implementation
